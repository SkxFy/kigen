# Kigen

Kigen is a procedural universe simulation focused on deterministic generation and physically plausible models.

The project starts with stellar and planetary systems and may later expand toward galaxies, life, civilizations, and large-scale universe simulation.

## Principles

* Deterministic generation from seeds
* Randomness defines initial conditions; physics determines the resulting systems
* Generated properties depend on each other
* Simulation and rendering remain separate
* Approximations are used where full physical simulation is impractical

## Current Status

Kigen is in early development.

The first milestone is to generate and visualize a deterministic star system from a seed.

## Technology

* C99
* CMake
* raylib
